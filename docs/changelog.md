## 2026-09-07 — .NET 9 Migration and Security Hardening

**Branch:** `chore/net9-migration`
**Merged:** Pull Request #1 → `master`
**Commit:** `fddfc0c`
**Author:** Ali Bin-Samida

### What Changed

#### Framework & Project Files

- Upgraded all three projects (`DVLD`, `DVLD_Buisness`, `DVLD_DataAccess`) from legacy .NET Framework project format to **SDK-style `.csproj`** files targeting **.NET 9**
- `DVLD` now targets `net9.0-windows` with `UseWindowsForms=true`
- `DVLD_Buisness` and `DVLD_DataAccess` now target `net9.0`
- Removed ~305 lines of legacy `<Reference>`, `<Import>`, and package config elements from the old project format
- Removed `Properties/AssemblyInfo.cs` from `DVLD_Buisness` and `DVLD_DataAccess` (auto-generated by SDK)

#### SQL Client Migration

- Replaced `System.Data.SqlClient` with **`Microsoft.Data.SqlClient` 6.0.3** across all data access classes
- Updated all `using` statements in `DVLD_DataAccess/`

#### Connection String Hardening

- Created `clsDataAccessSettings` with a fail-fast connection string resolver
- Resolution order: `DVLD_CONNECTION_STRING` environment variable → `dvld.env` file → exception
- Added `dvld.env.example` template (committed; contains placeholders only)
- Added `dvld.env` and `data.txt` to `.gitignore`

#### Security — Remember-Me

- Eliminated plaintext password persistence from the Remember-Me feature
- `clsGlobal.RememberUsernameAndPassword` now ignores the password parameter entirely and writes only the username to `data.txt`
- `clsGlobal.GetStoredCredential` always returns an empty password string
- Added explanatory comments documenting the intentional omission

#### WinForms Compatibility

- Added `Application.SetHighDpiMode(HighDpiMode.SystemAware)` to `Program.cs`
- Added `[DesignerSerializationVisibility]` attributes to WinForms controls where needed:
  - `ctrlDriverLicenseInfoWithFilter.cs`
  - `ctrlPersonCardWithFilter.cs`
  - `crlScheduleTest.cs`
  - `ctrlSecheduledTest.cs`
  - `frmAddUpdateUser.cs`
- Added `<ImportWindowsDesktopTargets>true</ImportWindowsDesktopTargets>` to `DVLD.csproj`

#### SQL Bug Corrections

- **`ChangePassword` (clsUserData):** Fixed missing or mismatched `@Password` parameter in the UPDATE query
- **`UpdateDetainedLicense` (clsDetainedLicenseData):** Fixed parameter mismatch between SQL SET clause and `AddWithValue` calls
- **`AddNewTestType` (clsTestTypeData):** Fixed inconsistent parameter naming (`@ApplicationFees` → correctly bound to `TestTypeFees` column)

#### .gitignore Updates

- Added `dvld.env` (local database configuration — must never be committed)
- Added `data.txt` (Remember-Me username cache — must never be committed)
